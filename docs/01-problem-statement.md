## 1. Problem

Aspiring engineers can learn programming languages and frameworks from tutorials, but nothing teaches **how software is actually delivered inside a company**: PRD reviews, CRs, go/no-go meetings, canary releases, production monitoring.

Interviewers for mid-level and senior roles probe exactly this, and candidates without industry experience can't answer convincingly.

## 2. Target Users

- Fresh graduates and bootcamp graduates aiming above entry level
- Career switchers moving into software engineering
- Developers at small companies or startups that never had a formal process
- Engineers preparing for interviews at large companies

## 3. Why Existing Solutions Fall Short

| Option | Gap |
|--------|-----|
| YouTube / blogs | Scattered and theoretical; no end-to-end flow |
| Courses (Udemy, Coursera) | Teach tools, not the process and the people around them |
| Interview-prep platforms (LeetCode, etc.) | Algorithms only, not real-world delivery |
| On-the-job learning | Takes years, and requires already having the job |

## 4. Why the SDLC Still Matters in the AI Era

**AI writes code faster than ever. But code isn't the product; shipped, working software is.**

Every line, whether a human or AI wrote it, still has to be reviewed, tested, approved, released safely and monitored. The more code AI produces, the more that process matters, and the engineer who owns it matters more.

- **AI writes the code. Engineers own the outcome.**
- **AI can't make the go/no-go call or lead an incident.**
- **Senior engineers are hired for judgement, not typing speed.**

> *"AI can write the code. Someone still has to ship it."*

## 5. Our Solution

An interactive, space-themed journey through **42 SDLC stations**, from PRD to production monitoring, with interview-ready explanations at every step. It is built using the very process it teaches, so every station includes real artifacts from this project.

## 6. Goals

1. **Product:** a learning tool real people use to prepare for interviews.
2. **Portfolio:** a showcase project demonstrating end-to-end ownership of the full SDLC.
